SYS / 04   How it works

A network
built from nodes.

Every Spyder Web unit acts as a node within the local network. Multiple nodes can relay information toward its destination.

NODE+NODE+NODE+NODE=SPYDER WEB
  • Node discoveryNodes find each other and join the local network.
  • Multi-hop routingA message can pass through intermediate nodes to reach its destination.
  • Local communicationText between nodes. No tower. No central server.
  • Position awarenessGPS gives each node positioning information.
  • Directional awarenessA digital compass supports heading and direction.

SYS / 07   Deployment scenarios

Built
for the edge.

01

Rescue

Application
Emergency and rescue operations
Why it matters
Cellular and internet service may be damaged or unavailable in an emergency.
Spyder Web role
Team members carry nodes that form a local text network, relaying messages hop by hop.
Future development · audio / PTT
02

Expedition

Application
Trekking, mountaineering and expeditions
Why it matters
Remote terrain often has no coverage, and groups spread out.
Spyder Web role
Each member carries a node. Text, GPS position and compass direction stay within the group network.
Future development · mapping
03

Industrial

Application
Mining and industrial operations
Why it matters
Operational areas can have unreliable or no cellular coverage.
Spyder Web role
Nodes across the site relay text messages without a tower or central server.
Future development · sensors and data logging
04

Field operations

Application
Small professional field teams
Why it matters
Teams often work where no network has been set up.
Spyder Web role
A temporary network that grows as nodes are switched on.
Future development · network management
